 # Curso de Desenvolvimento de Aplicativos com Firebase e Gemini do SENAI
### Descrição
Repositório destinado ao armazenamento de códigos, projetos e anotações referentes ao curso de Desenvolvimento de Aplicativos com Firebase e Gemini ministrado pelo SENAI. O foco é a integração de serviços de backend (Firebase) com inteligência artificial generativa (Gemini) no ecossistema de aplicações.

#### Tecnologias Abordadas
- Firebase (Authentication, Firestore, Storage, Hosting)

- Replit

- API do Google Gemini

- Ambientes de desenvolvimento e linguagens do curso (ex: Node.js, Python, JavaScript)

- Git



#### Estrutura do Repositório

**/aulas:** Scripts e implementações desenvolvidas durante as sessões do curso.

**/projetos:** Aplicações e projetos integradores.

**/docs:** Especificações técnicas, diagramas de arquitetura e materiais de apoio.
